Let’s do a quick recap of classes:</p><ul><li>A class is a set of languages containing languages of similar behaviour. It analyzes how efficient resources (time / space) are used at the edge of infinity.</li><li>Given X is a class, a X-hard problem is equally or more difficult than any problem in X, a X-complete problem is the one of the most difficult problems in X.</li></ul><p><strong>Class Hierarchy</strong></p><p>Now that we have learnt the fundamentals of computability and complexity, we will learn about the most basic complexity classes such as P and NP. To show how they would look like in real life, I couldn’t find a better way to show than chess. A chess position is given below where it is black player’s turn:</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*ezfMJ86ot3VM5l5JUU43qg.png" /></figure><p><em>P</em>:</p><ul><li><em>Formal definition</em>: A Deterministic Turing Machine decides in polynomial time if at least an input value is accepted.</li><li><em>Characteristics</em>: The code contains loops and simple recursions with a polynomial time bound.</li><li><em>Game Perspective</em>: For this to be succeeded, the whole system must be known by all nodes in the system, there is no such thing as searching other nodes or players.</li><li><em>A Most Expressive Problem</em>: Horn-Satisfiability (HORNSAT)</li><li><em>A Chess Problem</em>: <strong>Which moves can black player make?</strong></li></ul><p><em>NP</em>:</p><ul><li><em>Formal definition</em>: A Nondeterministic Turing Machine decides in polynomial time if at least an input value is accepted.</li><li><em>Characteristics:</em> The code contains at least one loop iterating exponentially or a recursive searching algorithm is implemented.</li><li><em>Game Perspective</em>: One player explores a whole system starting from a node and gaining more information.</li><li><em>A Most Expressive Problem</em>: Boolean Satisfiability (SAT)</li><li><em>A Chess Problem</em>: <strong>Can black player technically win the round?</strong></li></ul><p><em>co-NP</em>:</p><ul><li><em>Formal definition</em>: A Nondeterministic Turing Machine decides in polynomial time if every input value is accepted.</li><li>Characteristics and game perspective are similarly defined as NP</li><li><em>A Most Expressive Problem</em>: Boolean Tautology (TAUT)</li><li><em>A Chess Problem</em>: <strong>Does white player lose at all scenarios?</strong></li></ul><p><em>PSPACE</em>:</p><ul><li><em>Formal definition</em>: A Nondeterministic Turing Machine requires polynomial space in order to decide in polynomial time if at least an input value is accepted.</li><li><em>Characteristics</em>: The code contains multiple algorithms with searching capabilities as in NP, which can only respond to others’ previous moves in sequential order.</li><li><em>Game Perspective</em>: Multiple players with different strategies, which behave differently based on another player’s moves. The strategies of players are saved in polynomial space.</li><li><em>A Most Expressive Problem</em>: Satisfiability for Quantified Boolean Formulas (QSAT)</li><li><em>A Chess Problem</em>: <strong>Does black player have a winning strategy?</strong></li></ul><p><em>EXPTIME</em>:</p><ul><li><em>Formal definition</em>: A Deterministic Turing Machine decides in exponential time if at least an input value is accepted.</li><li><em>Characteristics</em>: Given multiple algorithms having different strategies as in PSPACE, each algorithm knows only a subset of the previous decisions of others’.</li><li><em>Game Perspective</em>: Multiple players, which not only behave differently based on other players’ previous moves, but also may have incomplete information about the current game status / move history when making a move.</li><li><em>A Most Expressive Problem</em>: Satisfiability for Dependency Quantified Boolean Formulas (DQSAT)</li><li><em>A Chess Problem</em>:<strong> Is black player more likely going to win the game?</strong></li></ul><p>The higher we go in complexity hierarchy, the less information we generally have access to. A quick recap:</p><ul><li><em>P vs NP</em>: In P, it has <strong>total</strong> information about the whole system; however in NP, it starts with <strong>partial</strong> information from a node in the system and explores to find an optimal solution.</li><li><em>(co-)NP vs PSPACE</em>: In (co-)NP, there is only one player (or multiple players working <strong>cooperatively</strong>) making a move to find an optimal solution; however in PSPACE, the player <strong>cannot guess</strong> the move of the others with certainty, so it has strategy instead.</li><li><em>PSPACE vs EXPTIME</em>: In PSPACE, a player has a winning strategy at some point knowing the <strong>whole</strong> current game status; however in EXPTIME, a player <strong>cannot know</strong> the whole current game status.</li></ul>
