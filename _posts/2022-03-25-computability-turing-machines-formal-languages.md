Logic Unit) and <em>RAM</em> (Random Access Memory) where all calculations happen in ALU and all programs are stored in RAM.</li><li><em>ALU</em> is created using <em>Logic Gates</em>, the most basic logical structures hard-coded as 1s and 0s using <em>circuits,</em> which is why when they say it is all 1s and 0s they are not wrong.</li></ul><p>This is the chain of abstraction. It is nearly impossible to create everything from scratch, but with abstraction it is just a matter of time. In the following section, we will see how theoretical computers called <em>Turing Machines</em> changed the perspective of an entire world.</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*L8YsBqlPQ7RDYXrwy7AHeQ.png" /></figure><p><strong>Turing Machines Demystified</strong></p><p>Turing Machine is a abstract representation of all functions in the computer science world. It can compute anything which is computable.</p><p>A Turing Machine M which is basically a “machine” which is allowed to modify the given <em>input</em> by operating on a <em>cell</em> basis, moving the head <em>left</em> and <em>right</em> or <em>none</em>, <em>reading</em> the inputs for example 0, 1, # and <em>writing</em> a letter depending on current <em>state</em>, in order to find out that an input is <em>accepted</em> / <em>rejected</em>. For an amazing introduction, you can check this out:</p><p><a href="https://erik-engheim.medium.com/turing-machines-for-dummies-81e8e25471b2">Turing Machines for Dummies</a></p><ul><li><em>To Halt (Stop)</em>: The Turing Machine ends in an infinite loop that does nothing.</li><li><em>To Accept</em>: The Turing Machine halts in a state which is an accepting one that we specified in definition of Turing Machine.</li></ul><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*ufyimd3iHNAeQfogdHDMrg.png" /></figure><p><strong>Introduction to Deterministic and Nondeterministic Turing Machines</strong></p><p>There are numerous variations of Turing Machines, and the 2 most important ones are:</p><ul><li><em>Deterministic Turing Machines (DTM)</em>: For each input, there is only a single path of computation. A word is accepted if the end state is an accepting one and vice versa.</li><li><em>Nondeterministic Turing Machines (NTM)</em>: There can be many parallel paths of computation. A word is accepted if at least one of the end states is accepting.</li></ul><p>Both Turing Machines are equivalent in terms of computational power: For each DTM, there exists a NTM, and for each NTM, there exists a DTM.</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*3swr78nPNhqNvm-8NJKWtA.png" /></figure><p><strong>The Question Is Not “What?” But “If?”</strong></p><p>A problem being computable means that there is an algorithm (not necessarily implemented) so that this problem can be calculated. There is no specification about complexity and efficiency of this problem, the main question is if there <em>exists</em> an algorithm.</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*YpciirmlRojH9iovMbDUJg.png" /></figure><p><strong>Letters to Words to Languages to …</strong></p><p>In formal languages theory, there are clear definitions of every aspect we will discuss in the next sections:</p><ul><li><em>Letter</em>: It can be a number, an alphanumeric letter, but most basically we can represent any letter using 1s and 0s.</li><li><em>Word</em>: A meaningful combination of letters which represents for example an argument, we will see it mostly as an argument passed in an algorithm.</li><li><em>Language</em>: A list of words that are accepted by a Turing Machine. We will see it mostly as the word problems (if a word is contained in a language) which also shows whether given argument gives a YES or NO instance.</li></ul><p>And also we will mostly see classes as <em>set of languages,</em> containing languages of similar behaviour.</p>
