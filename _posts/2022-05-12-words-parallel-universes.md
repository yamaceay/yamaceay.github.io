<figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*cWJD2PEduDqGS97uvuq7TQ.png" /><figcaption>Source: <a href="https://chemical-collective.com/de/blog/Was-ist-1cp-LSD%3F-Was-sind-seine-Auswirkungen-und-wo-kann-ich-es-kaufen/">https://chemical-collective.com/de/blog/Was-ist-1cp-LSD%3F-Was-sind-seine-Auswirkungen-und-wo-kann-ich-es-kaufen/</a></figcaption></figure><p>Let’s assume, a word in a parallel universe looks like a tree of letters instead of a sequence, and we cannot enumerate the letters in words anymore. Ask yourself these questions:</p><ul><li>How different would the languages look like?</li><li>How much more complex would be the algorithms?</li><li>How could books adapt to the change?</li><li>What would be the consequences?</li></ul><p>In the following sections, I will introduce some of the concepts from the formal languages &amp; automata, then re-define and analyze the grammar types.</p><h4>Introduction to Formal Languages &amp; Automata</h4><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*ptA1az6KkHyuCyixUXrzDA.jpeg" /><figcaption>Source: <a href="http://www.discmath.ulg.ac.be/flans/index.html">http://www.discmath.ulg.ac.be/flans/index.html</a></figcaption></figure><p><em>If you don’t understand the concepts, you can find additional sources at the end.</em></p><p><strong>Important Definitions</strong></p><p><em>Alphabet</em>: A set of letters <em>Σ = {a_{1}, …, a_{m}}</em>. Each letter stands for a value.</p><p><em>Word</em>: A sequence of letters <em>w = (w_{1}, w_{2}, …, w_{l})</em> or simply <em>w_{1} w_{2} … w_{n}</em>, where <em>∀ i ∈ {1, …, l} . w_{i} ∈ Σ</em>. Each word stands for an argument.</p><p><em>Language</em>: A set of words. Each language stands for a problem, which accepts / rejects words.</p><p><em>Grammar</em>: Basically a set of rules and letters, which define the syntax of a language. It can create any word in a language. Two types of grammars worth considering in this article:</p><ul><li><em>Regular (or type-3) grammar</em>: It can create a word from left to right<em>*[1]</em> (1 direction)</li><li><em>Context-free (or type-2) grammar</em>: can create a word in both directions (2 direction)</li></ul><p><em>Automaton</em>: Similarly a set of states and letters, which define the syntax. It accepts the words of a language, and rejects other words.</p><p><em>Word Problem</em>: The algorithmic problem of whether a word is accepted by a language. In general, word problems can be solved using top-down recursive formulas<em>*[2]</em>. If root node satisfies the criteria, the word is included in the language.</p><p><em>Notes:</em></p><p><em>*[1]: There are left-regular grammars which can work in reverse direction, each forms a reverse language of a right-regular language, so each grammar can be represented by right-regular grammars.</em></p><p><em>*[2]: Not always word problems are solved recursively. Word problem of regular grammars requires O(n) ( = linear) time bound and context-free grammars O(n^3) ( = cubic) time using a naive implementation.</em></p><h4>Words &amp; Grammars in Our Universe</h4><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*dPqvLTRmWQPE4OzTJpWHPw.png" /><figcaption>A word graph</figcaption></figure><p><strong>Words</strong></p><p>Previously, we have defined words as linked lists, sequences, list of symbols.</p><p>Not only a linked list can store a word, but also a linear graph with:</p><ul><li>Nodes: <em>{w_{1}, …, w_{n}}</em></li><li>Edges: <em>{{w_1, w_2}, …, {w_{n-1}, w_{n}}</em>.</li></ul><p>In the illustration, we can see a linear graph representing a word, which starts from node <em>w_{1}</em> and ends at node<em> w_{7}</em>.</p><p>In this case, we can also make an observation, that each node can have max. 2 neighbors.</p><p><strong>Grammars</strong></p><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*2RsHMAJBlJCpsgvLMKWfIA.png" /><figcaption>Source: <a href="https://en.wikipedia.org/wiki/Formal_grammar">https://en.wikipedia.org/wiki/Formal_grammar</a></figcaption></figure><p>A grammar <em>G = (V, Σ, P, S) </em>consists of:</p><ul><li>Set of variables, e.g. <em>V ={A_{1}, A_{2}, …, A_{r}}</em></li><li>Set of symbols, e.g. <em>Σ = {a_{1}, a_{2}, …, a_{m}}</em></li><li>Set of rules, e.g. <em>P = {A_{1} → A_{1}a_1 | a_1A_{1} | a_{1}, A_{2} → A_{3}A_{4}}</em></li><li>Starting variable, e.g. <em>S = A_{j}</em></li></ul><p>Rules of grammars look like as follows:</p><ul><li>Regular grammar: <em>A → ε | h| Bh | hC</em></li><li>Context-free grammar: <em>A → ε | h| Bh | hC | BC |</em></li></ul><h4>Other Universes</h4><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*xG2KaBDaV-3JThEUxhLhsQ.jpeg" /><figcaption>Source: Veritasium | Youtube.com</figcaption></figure><p>We have seen that normally a word can be represented as a graph in total order.</p><p>Now we assume there is a parallel universe called 𝒜.</p><p>The words in 𝒜 are represented by graphs in partial order.</p><p>In opposite to a totally ordered graph, not all pairs of nodes can be compared, that’s why a graph in partial order has more than one linear representations.</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*DnitfylPdRtiWpNZdgq4rA.png" /><figcaption>Source: <a href="https://notes.eddyerburgh.me/distributed-systems/coordination-and-time">https://notes.eddyerburgh.me/distributed-systems/coordination-and-time</a></figcaption></figure><p>That means, words in 𝒜 cannot be defined using one string.</p><p>Instead, we define words as d-ary trees where:</p><ul><li>n is the number of nodes,</li><li>ε is the root node and</li><li>d is the chromatic index ( = max. number of neighbor connections) and it is a number in range of 2 to m, also the number of letters in Σ.</li></ul><p>Each node can be named by its history of descendants, so that the variables can be unique, which is why backtracking fits very well for naming convention. Then the words are defined recursively using backtracking. Let h the depth of recursion:</p><p><em>Recursion start (h = 0)</em>: <em>w_{()} = ε</em> is the blank word.</p><p><em>Recursion step (h &gt; 0)</em>: the node <em>ww_{i_{h}} = w_{(i_{1}, …, i_{h-1}, i_{h})}</em> at level h has a parent node <em>w = w_{(i_{1}, …, i_{h-1})}</em> and is connected to the parent over <em>i_{h}</em>-th letter in the alphabet.</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*Qoz6jU-B-rIdHqBhouA7CA.png" /><figcaption>The (undirected) graph of a word in a parallel universe with d = 3 and n = 7</figcaption></figure><h4>Open Questions &amp; Conjectures</h4><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*89_yYdtZ20fBAKE4YYWejw.jpeg" /><figcaption>Source: <a href="https://pixabay.com/de/images/search/letztes%20teil/">https://pixabay.com/de/images/search/letztes%20teil/</a></figcaption></figure><h4>How would a regular language in 𝒜 look like?</h4><p>Languages created by regular grammars are considered as read-only (or write-but-never-look-back) languages.</p><p>Applying it to the parallel universe, it could be visualized as a DAG (Directed Acyclic Graph).</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*Q04bbk3e7kcJpEKXeBMGPA.png" /><figcaption>Example of DAG</figcaption></figure><h4>How would a context-free language in 𝒜 look like?</h4><p>Context-free grammars have a more complex definition than regular grammars.</p><p>Instead of regular language, letters can be appended at the right-end, or left-end. In this context, left means root and right means leaves.</p><p>It can be illustrated as an undirected graph, in opposite to regular grammars in 𝒜.</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*jo600p5AvB6lrRQjW0TgQg.png" /></figure><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*pvswxc-vCTifFqSG0Ur_0Q.png" /></figure><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*qMKxHmpM-S93rAyWOJWFYg.png" /><figcaption>1 → 2: EY → HEY, 2 → 3: I → HI</figcaption></figure><h4>Is a word in 𝒜 equal to a language in our universe?</h4><p>Yes. As we have mentioned before, a word in 𝒜 is saved in a graph in partial order.</p><p>So there are many configurations that a graph can have, because not all pairs can be compared.</p><p>If each end configuration ( = path starting from the root node, ending at a leave) is stored in a set of words, it becomes a language in our universe.</p><p>Then a language in 𝒜 is equivalent to a class of languages.</p><h4>What are the complexity classes of these grammars in 𝒜?</h4><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*5x5NYl3eqqxXBVYnhDX7HA.jpeg" /><figcaption>Source: <a href="https://jeremykun.com/2012/02/29/other-complexity-classes/">https://jeremykun.com/2012/02/29/other-complexity-classes/</a></figcaption></figure><p><em>Regular grammars</em>: There is no efficient algorithm, which can solve word problem in altered regular grammar in polynomial time, because the word is non-deterministic and each path of word starting from root node is polynomial-length. It is a NP problem, and can be solved using dynamic programming.</p><p><em>Context-free grammars</em>: Word problem in altered context-free grammars cannot be solved using NP-algorithms, because it has to store the directions for each step in polynomial-space. It is a PSPACE problem.</p><p>In the following section, we’ll justify those statements in context of most representative logical problems of NP and PSPACE. Let’s start with a quick introduction:</p><h4>NP vs PSPACE</h4><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*qePEHHyA4xJ2VCecKGuICA.jpeg" /><figcaption>Source: <a href="https://www.facebook.com/annoyingorange/photos/single-player-vs-multiplayer!-hahaha!!/10154705030291296/?_rdr">https://www.facebook.com/annoyingorange/photos/single-player-vs-multiplayer!-hahaha!!/10154705030291296/?_rdr</a></figcaption></figure><p>A NP problem can be depicted as a game where a player explores an environment and tries to reach a happy ending. If a desired solution exists, the player wins, otherwise loses.</p><p>However, a PSPACE problem is illustrated as a game where two players play against each other using different strategies. If one player has a winning strategy, the other player loses.</p><p>Regular and context-free grammars can be seen as 1-player and 2-player games respectively.</p><p><strong>The most representative problems</strong></p><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*GQ_92xfjHL8H4tLJuBYx2A.jpeg" /><figcaption>Source: <a href="https://medium.com/introduction-to-knowlegde-representation/propositional-logic-and-sat-problems-c0a3edac6a26">https://medium.com/introduction-to-knowlegde-representation/propositional-logic-and-sat-problems-c0a3edac6a26</a></figcaption></figure><p>Given a boolean formula F with arguments <em>x_{1}, …, x_{n} ∈ {0, 1}</em>:</p><p><em>SAT (Satisfiability Problem, NP-complete): </em>Evaluate the statement <em>∃ x_{1} : … : ∃ x_{n} : F(x_{1}, …, x_{n})</em> and return a true solution if possible.</p><p><em>QSAT (Quantified Satisfiability Problem, PSPACE-complete)</em>: Evaluate the statement <em>Q_{1} x_{1} : … : Q_{n} x_{n} : F(x_{1}, …, x_{n}); Q_{1}, …, Q_{n} ∈ {∃, ∀}</em> and return a true solution for each existential quantified variable if possible.</p><p>Given:</p><ul><li>an alphabet <em>Σ</em></li><li>a word argument <em>w </em>of length h</li><li>the characteristic function of rules <em>E</em> so that <em>E((x, y)) = 1, if x → y</em> is a valid rule, otherwise 0.</li></ul><p>The top-down boolean formulas verifying that a word is accepted in a language:</p><p>Regular Grammars</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*aZcAHKeHmAqrVS8DKzYZtg.png" /><figcaption>If any node has an invalid child node, the word is excluded from the language.</figcaption></figure><p>Context-free Grammars</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*XTLZkiNx_jAj4_NSEpc6Xg.png" /><figcaption>If any node has an invalid child node as word + letter (if left to right) and there is no valid child node of root as letter + word (if right to left), the word is excluded from the language.</figcaption></figure><p><strong>Complexity of regular grammars in 𝒜</strong></p><p>As we can see, the first formula includes only ∃ (existential quantifier) at any step. If the recursion is eliminated, it becomes:</p><ul><li><em>∃ x_{1} : … : ∃ x_{n} : (A(x_{1}) ∧ A(x_{1}x_{2}) ∧ … ∧ A(x_{1}…x_{n}))</em></li></ul><p>and it can be solved using SAT.</p><p><strong>Complexity of context-free grammars in 𝒜</strong></p><p>Besides existential quantifier, the second formula includes but also ∀ (universal quantifier). If the recursion would be eliminated, it could be solved by a QSAT algorithm.</p><h4>How could this adjustment affect type-1 and type-0 languages?</h4><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*TmmIYDK6KhCTqyCb09DY6A.jpeg" /><figcaption>Source: <a href="https://www.rnd.de/panorama/starke-explosion-nahe-des-flughafens-von-bangkok-elf-verletzte-YIXKMQ6Z3SIPPF5273DEZ6XBKM.html">https://www.rnd.de/panorama/starke-explosion-nahe-des-flughafens-von-bangkok-elf-verletzte-YIXKMQ6Z3SIPPF5273DEZ6XBKM.html</a></figcaption></figure><p>I leave this question unanswered. But it is interesting to note:</p><p><em>Context-sensitive (type-1) languages</em>: They can additionally have letters on the left ad right side of rules, in opposite to context-free languages.</p><ul><li>For example: <em>jAk → jak.</em></li><li>The complexity: NLINSPACE (non-deterministic Turing Machine uses linear space).</li></ul><p>In case of <strong>𝒜</strong>, the number of possible combinations on the right side of the rule is proportional to the number of all subsets of alphabet.</p><p>That’s why the number of branches for each node scales with 2^d (the number of letter combinations) instead of d ( = the number of letters).</p><p>So my guess for the complexity of type-0 and type-1 languages would be EXPTIME-hard, because it would take exponential time at each recursion step.</p><h4>Final Thoughts</h4><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*Vwbewk6y_ycrjyBjnxK20Q.jpeg" /><figcaption>Source: <a href="https://coachingpartner.net/cp/en/live-world-possibilities/">https://coachingpartner.net/cp/en/live-world-possibilities/</a></figcaption></figure><p>Firstly, we made a brief introduction to the formal languages &amp; automata, complexity theory and logical problems.</p><p>Then we applied what we have learned in describing a parallel universe where words are represented using trees (instead of linked lists), and analyzed the behaviour of regular and context-free grammars among grammar types.</p><p>Using satisfiability problems and single-player / multi-player game analogy, we showed that the regular grammars become a NP problem, whereas the context-free grammars become a PSPACE problem.</p><p>Finally, we suggested that the lower types of grammars would be at least EXPTIME-hard.</p><p>I hope you found the article inspiring, thank you for your interest, and feel free to contact me on LinkedIn if you think I made a mistake somewhere!</p><p><em>This article is built on top of my other articles:</em></p><ul><li><a href="https://yamaceay.medium.com/computability-turing-machines-formal-languages-6185f2dac94f"><em>What is Letter, Word, Language?</em></a></li><li><a href="https://yamaceay.medium.com/complexity-introduction-da2035f72209"><em>What is a Complexity Class?</em></a></li><li><a href="https://yamaceay.medium.com/complexity-classes-and-their-limitations-6952455fa5a8"><em>What is NP, PSPACE?</em></a></li><li><a href="https://yamaceay.medium.com/complexity-comparison-of-different-satisfiability-problems-e8f668167bab"><em>What is SAT, QSAT?</em></a></li></ul><p><em>And also special thanks to </em><a href="http://csacademy.com"><em>csacademy.com</em></a><em> for interactive GUI for designing graphs and </em><a href="http://overleaf.com"><em>overleaf.com</em></a><em> for LaTeX rendering.</em></p><p><em>Snapshots with unknown sources are all taken by me.</em></p>
