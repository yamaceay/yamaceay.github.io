<figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*2ZhU3FOF7BnC3fz_DP8KEw.png" /><figcaption>Source: <a href="https://realpython.com/python-lists-tuples/">https://realpython.com/python-lists-tuples/</a></figcaption></figure><p>Sets and tuples are the basic list structures in the math language.</p><p>In the following, we will see very important features of sets and tuples along with the operations defined on sets and tuples.</p><p>Let’s start with the features.</p><h4>Features of Set</h4><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*vSGUP3cMvvzO51PuCNrE2A.png" /><figcaption>Source: <a href="https://realpython.com/python-sets/">https://realpython.com/python-sets/</a></figcaption></figure><p><em>Set </em>is a list of values.</p><p>{1, 2, 3} is a set.</p><p>{1, 1, 3} is equal to {1, 3} because duplicates are not allowed.</p><p>{1, 2, 3} is equal to {1, 3, 2} because the sequence order of elements is not stored.</p><p>1 ∈ {1, 2, 3} but 4 ∉ {1, 2, 3}.</p><p>Subset notation: {1, 2} ⊆{1, 2, 3} but {1, 4} ⊈ {1, 2, 3}.</p><p>2^A = {B | B ⊆ A} is called a power set and contains every subset of A.</p><p>B ∈ 2^A, if and only if B ⊆ A.</p><p>The function “||” outputs the number of elements in a set: |{1, 2, 3}| = 3.</p><p>{} is the empty set and the only set which “||” maps to 0.</p><p>{1, 2, …, n} has the start index 1, the step pattern 2–1 = 1, and the end index n.</p><p>Special cases: {} if n &lt; 1, {1} if n = 1.</p><p>{1, …, 10} includes all numbers from 1 to 10.</p><p>We can also represent it as {i is a (natural) number | i ≥ 1, i ≤ n} = {i is a (natural) number | 1 ≤ i ≤ 10}.</p><p>Notice that “,” on the right side is equal to logical AND.</p><p>ℕ is the set of all natural numbers starting from 0, 1, … and can be represented as {0, 1, …}, since there is no upper limit.</p><p><strong>ℝ </strong>is the set of all real numbers.</p><p>The real numbers between a and b (inclusively) are defined as [a, b].</p><p>If a is excluded from the interval: (a, b] and vice versa.</p><h4>Features of Tuple</h4><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*hfuev7Io_YTVj8b8Lm5ljg.png" /><figcaption>Source: <a href="https://www.dotnetperls.com/tuple-fs">https://www.dotnetperls.com/tuple-fs</a></figcaption></figure><p><em>Tuple </em>is an ordered list of values.</p><p>Unlike sets, it can hold sequence order.</p><p>(1, 2, 3) is a tuple.</p><p>Duplicate values are allowed, for example: (1, 2, 2, 3) is not equal to (1, 2, 3).</p><p>(1, 2, 3) is not equal to (1, 3, 2).</p><p>(1, 2, …, m) defines the range of numbers as a tuple array.</p><p>As a shorthand notation, we can define (i)_{i ∈ {1, …, n}} or (i)_{1 ≤ i ≤ n}, it is similar to {i | 1 ≤ i ≤ n} in sets.</p><h4>Operations</h4><p>Metaphorically, sets are the arrays and tuples are the structs in C.</p><p>In an array, the content of the array and overall quantity is much of importance, while in a struct, the order and semantics of values play a significant role. For example:</p><ul><li>5 ∈ (3, 5, 10) doesn’t make sense, but 5 = (3, 5, 10)_2 makes sense, because a tuple is a struct and each item in a tuple stores a different ‘column’ feature.</li><li>If we really would want to check if 5 ∈ (3, 5, 10), then it should have been defined as a set, since the order is not relevant.</li></ul><p>So there is a clear distinction between sets and tuples, and in which context they are used.</p><p>The operations of sets and tuples are shown below:</p><h4>Set Operations</h4><p><em>Union</em>: A ∪ B means: {x | “x is in A or in B”} = {x | x ∈ A ∨ x ∈ B}. Assuming A_1, …, A_n are all sets, ⋃_i A_i defines the union of all sets.</p><p><em>Intersection</em>: A ∩ B means: {x | “x is in A and in B”} = {x | x ∈ A ∧ x ∈ B}. Assuming A_1, …, A_n are all sets, ∩_i A_i defines the intersection of all sets.</p><p><em>Difference</em>: A \ B means: {x | x is in A but not in B} = {x | x ∈ A ∧ x ∉ B}.</p><p><em>Product</em>: A × B means: {(a_i, b_j) | a_i ∈ A, b_j ∈ B}. Assuming A_1, …, A_n are all sets, ∏_i A_i defines the (cross) product of all sets. If all sets A_i are identical, ∏_{1 ≤ i ≤ n} A equals to A^n.</p><h4>Tuple Operations</h4><p><em>Indexing</em>: Assuming w = (w_1, …, w_n) is a tuple. w_i selects the i-th element from the tuple w.</p>
