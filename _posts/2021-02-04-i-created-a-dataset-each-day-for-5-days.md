<p>Here’s what I’ve learned so far…</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*jUMexU3zpd10SkvMzt64oA.jpeg" /><figcaption>Source: Pixabay, Pexels.com</figcaption></figure><p>Nowadays, I see a lot of challenges such as #66DaysOfData and #90DaysOfCoding, and the success stories of people challenged themselves to learn anything from scratch in such a short period of time. With so many options, it can be even <strong>more challenging</strong> to pick the right challenge or create yourself. I decided to create the <strong>hardest challenge</strong> I could ever imagine: Creating a dataset using pure Web Scraping every single day for 5 days. Here’s the rules:</p><ul><li><strong>Importing</strong> a Kaggle dataset is not allowed.</li><li><strong>API access</strong> is forbidden too.</li><li>No <strong>fancy</strong> Python packages, there should be no function allowing you access content in a single line or whatsoever.</li><li>Similarly, no<strong> Kernel or Notebook</strong>, only pure Script.</li><li>You need to decide what to do during the day, <strong>no tomorrow plans.</strong></li><li>And you have to choose a challenge more difficult than yesterday, <strong>each day</strong>.</li></ul><p>It was literally an impossible challenge for me. That’s why I choose it. These are my real experiences, without exaggeration or cheating.</p><p>My preferences:</p><ul><li><strong>Scripting language: </strong>Python</li><li><strong>Scraping tool:</strong> Selenium (and Requests if necessary)</li><li><strong>Coding environment:</strong> PyCharm</li></ul><p><strong>NOTE: </strong>I created datasets just for educational purposes. If you have problems or concerns regarding data policies, please leave a private note here.</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*DUGdol3-e4DO60zG41X1cw@2x.jpeg" /><figcaption>Source: Matt Howard, Unsplash</figcaption></figure><p>Let’s proceed with my 5-day journey.</p><h4>Day 1 — A Soft Beginning</h4><p>I picked a topic randomly: “MBTI-Types”. Luckily, I found one of the old-school dating forums with no signs of activity: Project Evolove (<a href="http://www.projectevolove.com/">http://www.projectevolove.com/</a>). From the point of view of a programmer, it is a priceless gift. No complexities, just pure CSS and HTML manipulations, consistent classes and names. It was a good beginner-level exercise:</p><pre><code>from selenium import webdriver
driver = webdriver.Chrome(executable_path=&lt;path&gt;) # opens a new chrome driver 
# &lt;path&gt;: path to the chrome driver app</code></pre><pre><code>driver.get(&lt;url&gt;) # opens the given web page</code></pre><pre><code>driver.quit() # closes the current driver</code></pre><pre><code>driver.find_elements_by_css_selectors(&lt;selector&gt;)# returns a list of element objects</code></pre><pre><code># &quot;#&lt;id&gt;&quot;: id selector
# &quot;.&lt;class&gt;&quot;: class selector
# &quot;&lt;element&gt;&quot;: element selector 
# &quot;&lt;parent&gt; &gt; &lt;child&gt;&quot; direct child of parent</code></pre><pre><code>element.get_attribute(&lt;attr&gt;) # returns the attribute
 
# &quot;innerHTML&quot;: HTML code of elements inside of the element
# &quot;innerText&quot;: The content of element as string
# &quot;href&quot; (if element is of &quot;a&quot;-type): returns link of &quot;a&quot;-element
# &quot;outerHTML&quot;: HTML code of element</code></pre><p>I scraped every 500 pages of forum in the single run. The data collection took 2–3 hours, publishing on Kaggle an hour. Easy peasy.</p><p>Day 1/5</p><ul><li><strong>Time period: </strong>3–4 hours</li><li><strong>Improvements: </strong>Selenium Basics and Chrome Developer Tools</li></ul><p><a href="https://www.kaggle.com/yamaerenay/mbtitypes">MBTI-Types &amp; Enneagram Texts</a></p><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*iygoBgyEVEP5BeK1jxmpGA@2x.jpeg" /><figcaption>Source: Patrick Tomasso, Unsplash</figcaption></figure><h4>Day 2 — Here We Go Again</h4><p>I thought the data that I published is too small and insufficient, that’s why I decided to build a complementary dataset. I picked a seemingly large-scale website called 16 Personalities (<a href="https://www.16personalities.com/">https://www.16personalities.com/</a>) and level up the game of yesterday. It was not hard at all to scrape the well-documented information of personality types, which I did in 30 minutes. I had to spice it up. At that time I felt completely lost, I noticed the Statistics part of the website. Scraping the global distribution of personality types: Perfect! But wait, which one to choose?</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*YN5encxP75eSXZsS9dqR9A.png" /></figure><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*lg4EaX9ww1FiXTsGJWdVjQ.png" /><figcaption>Question: Global Or Country?</figcaption></figure><p>If you are simply interested in global distribution, then don’t hesitate to choose the left option. Otherwise, pick always the right option, because <strong>the bigger the data, the more valuable the dataset</strong>. I scraped the list of countries from other websites and searched iteratively for countries and finally scraped their distributions in just an hour. Data Preparation took an hour and finally I published the dataset on Kaggle.</p><p>Day 2/5</p><ul><li><strong>Time period:</strong> 3 hours</li><li><strong>Improvements:</strong> Tips and tricks for I/O Operations in Python, JSON manipulation skills</li></ul><p><a href="https://www.kaggle.com/yamaerenay/mbtitypes-full">MBTI-TYPES Data</a></p><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*vSRK6UaE0995hju9PfcYsg@2x.jpeg" /><figcaption>Source: Javier Allegue, Unsplash</figcaption></figure><h4>Day 3 — There It Starts</h4><p>At this day, I had a lot of assignments and works related to uni, so all I had was 2 to 3 hours. After 2 days of pure but easy success, I decided to <strong>change the concept</strong>. Enough of personality stuff. I picked “website statistics”. This is a bit challenging because it is hard to find suitable information published online for free. I found a well-structured tabular data published on Amazon Alexa (<a href="https://www.alexa.com/topsites/countries">https://www.alexa.com/topsites/countries</a>) showing the most popular websites on a global scale. The same question, again:</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*ypzlpkrDI5hDkpR9jtBKFA.png" /></figure><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*7tzZf1Q_MtYGk4ENYmtpkQ.png" /><figcaption>Question: Global or Country?</figcaption></figure><p>You know the answer. It took 2 hours to scrape the whole data. Data Wrangling and publishing to Kaggle took 1–2 hour(s). At the end of the day, it felt like one, two, three, boom: All I did was finding similar elements, saving into lists and converting it to a more structured format like CSV.</p><p>Day 3/5:</p><ul><li><strong>Time period: </strong>3–4 hours</li><li><strong>Improvements: </strong>Dealing with more dynamic websites, paying more attention to Robots.txt files</li></ul><p><a href="https://www.kaggle.com/yamaerenay/top50websites">Top 50 Most Popular Websites by Countries</a></p><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*DRz0iUrlxHdGwBZexFeMIw@2x.jpeg" /><figcaption>Source: Xhoni Mykaj, Unsplash</figcaption></figure><p>One day later, I wanted to go through some real challenge, which brings us to the Day 4.</p><h4>Day 4 — Another Level</h4><p>The past 3 days were just text, text, text… Getting text content is no-brainer, scraping images is cool. It’s time to spice it all up. It is a lot harder to decide <strong>which </strong>than<strong> how</strong>. I have the option for scraping a free stock website e.g. Unsplash by an arbitrary category -it can be anything from animals to people, from nature to fashion-. There is also a much more difficult option: Google Images (<a href="https://images.google.com/">https://images.google.com/</a>), which I chose without hesitation. A few reasons it is so hard to scrape:</p><ul><li><strong>Over-Nested Structure:</strong> element in element in element … Inception at HTML level</li><li>Machine-generated <strong>ids</strong> for elements: it is hard to find the general use cases</li><li><strong>No Scrolling, No Data:</strong> It is necessary to implement scrolling-under function to load more results</li><li><strong>Disorganized</strong> image containers (with different sizes)</li><li><strong>Advertisements</strong> shown as images</li></ul><p>My deep interest in cars motivated me to scrape the most popular 50 car brands in US from Carlogos.org (<a href="https://www.carlogos.org/popular-car-brands/">https://www.carlogos.org/popular-car-brands/</a>). With a quick research, I figured it out how to save images: I searched iteratively 100 photos of each brand, scraped the links of images and downloaded images as follows:</p><pre><code>from selenium import webdriver
import requests
from PIL import Image
import io
driver = webdriver.Chrome(executable_path=&lt;path&gt;)
driver.execute_script(&#x27;window.scrollTo(0, document.scrollHeight)&#x27;) # scrolls to the bottom of the page (document.scrollHeight: full height of shown part of the website)</code></pre><pre><code>driver.find_elements_by_css_selectors(&lt;path_to_img&gt; &gt; img) # returns list of images
img.get_attribute(&quot;src&quot;) # returns the list of links of images (different from &quot;href&quot; attribute of &quot;a&quot;-element</code></pre><pre><code>page = requests.get(link) # returns the image on a new tab
image_bytes = io.BytesIO(page) # returns page in bytes
image = Image.open(image_bytes).convert(&#x27;RGB&#x27;) # converts bytes to images
with open(&lt;fpath&gt;, &quot;w&quot;) as file:
  image.save(file, &quot;JPEG&quot;) # saves image as JPEG file</code></pre><p>Coding took not so long: 2 hours total. It takes so much longer for program to get the all links of images throughout the webpage while scrolling under until 100 images are found.</p><p>Day 4/5</p><ul><li><strong>Time period:</strong> 4 hours</li><li><strong>Improvements: </strong>Scrolling, Downloading Images</li></ul><p><a href="https://www.kaggle.com/yamaerenay/100-images-of-top-50-car-brands">Car Brands Images</a></p><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*cDalDjb7oQufu1ResqAHTA@2x.jpeg" /><figcaption>Source: Joshua Earle, Unsplash</figcaption></figure><h4>Day 5 — It Could Not Be More Difficult</h4><p>Day 5. I dared to myself, no more easy stuff, no more simple websites. Youtube:</p><ul><li>no permission without accepting <strong>cookies</strong></li><li><strong>brand-new</strong> HTML elements invented by Youtube itself (starting with yt-)</li><li>(possibly) advanced bot <strong>trackers</strong></li><li>HTML <strong>inception</strong> at a much deeper level</li></ul><p>I challenged myself to collect the <strong>transcripts</strong> of most popular ads. Thanks to Think With Google (<a href="https://www.thinkwithgoogle.com/marketing-strategies/video/leaderboards/">https://www.thinkwithgoogle.com/marketing-strategies/video/leaderboards/</a>) leaderboards, I could easily find the ads, however I could not find a way to interact with the external links to Youtube videos.</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*3nYQjK5qP2k_8Lq2JGuJsA.png" /><figcaption>Videos Playing Internally, Think With Google</figcaption></figure><p>I had to make a search on Youtube using URL query as follows:</p><pre><code>import urllib
urllib.parse.quote_plus(&quot;no more scraping&quot;)
=&gt;&quot;no+more+scraping&quot;</code></pre><pre><code># and concatenate it with the base url
&quot;https://www.youtube.com/results?q=no+more+scraping&quot;</code></pre><p>At each search result, I picked the first one, it doesn’t matter if it is the right one or not. Then I tried to scrape the automatically generated English subtitles, but the cookie policies didn’t allow me to do it properly. Here are the tricks that I tried using to scrape in a more advanced way:</p><ul><li>Coding <strong>time breaks </strong><code>driver.implicitly_wait(&lt;seconds&gt;) or time.sleep(&lt;seconds&gt;)</code> (Didn’t work)</li><li>Accessing random <strong>Proxy</strong> IPs from different countries using “http-request-randomizer” package (Didn’t work due to a driver problem that I could not fix)</li><li>Copy-pasting advanced codes from Stack Overflow (That failed too)</li></ul><p>Rule Break: Then I have met “youtube-dl”, a beautiful Python package which allows you to scrape content of Youtube videos without dealing with the cookie policies, bot detection problems, yt-Elements. That was it. It took nearly 30 min to find the subtitles of approx. 550 videos.</p><p>Day 5/5</p><ul><li><strong>Time Period:</strong> 7–8 hours</li><li><strong>Improvements: </strong>Proxy using “http-request-randomizer”, waiting function of selenium and time.sleep(), youtube-dl for Youtube scraping</li></ul><p><a href="https://www.kaggle.com/yamaerenay/most-popular-youtube-ads-20172020">Most Popular Youtube Ads</a></p><p><strong>End of the Journey</strong></p><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*iiY0aMgNhAxc4cS7b387nA.png" /><figcaption>My Datasets on Kaggle</figcaption></figure><p>Before 5 days, I didn’t have the mindset of web scraping, <strong>maybe still not</strong>. It was a priceless experience — starting from simple tabular datas, to much more advanced topics.</p><p>It is worth noting that you need web scraping for only special occasions. If not necessary, <strong>don’t waste your time</strong> scraping, use the most practical tool e.g. you can download public datasets or access free APIs.</p><p>However, it comes in handy if you know how to do it, especially when a <strong>very specific task</strong> is given such as</p><ul><li>“Where to find the top 50 most popular websites in India?”</li><li>or “Name the top 5 keywords of Nike advertisements” etc.</li></ul><p>And also it helps you practice:</p><ul><li>how to do I/O operations most efficiently</li><li>how to interact with servers properly</li><li>how to convert and structure datatypes</li></ul><p>Today, what I want from you is to <strong>challenge yourself</strong>, no matter which challenge. Set yourself a goal and write a journal of your experiences. If you have picked my challenge, you can also try:</p><ul><li>Dark Web Scraping</li><li>Dealing with Captcha</li><li>Automated Web Crawling</li></ul><p>Feel free to try it yourself. Happy #5DaysOfScraping!</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*kYKaN7n0Sz9dxlyY_dZZuA.jpeg" /><figcaption>Source: Markus Spiske, Pexels.com</figcaption></figure>
