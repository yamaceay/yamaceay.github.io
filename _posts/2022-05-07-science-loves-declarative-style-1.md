<h4>… so why are you still coding in imperative style?</h4><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*t0J7aaw8nmEIqbGvQQqW7w.jpeg" /><figcaption>Source: <a href="https://datwyler.com/de/technology-innovation">https://datwyler.com/de/technology-innovation</a></figcaption></figure><p><em>It is the first chapter of Science Loves Declarative Style, and you can navigate to the next chapter clicking </em><a href="https://yamaceay.medium.com/science-loves-declarative-style-2-806c5f28e96d"><em>here</em></a><em>.</em></p><p>Imperative programming has been the most popular paradigm for a century.</p><p>Most of the technological breakthroughs are achieved using imperative programming languages such as Java, C/C++, JavaScript, Go.</p><p>We cannot really imagine how to program a simple for loop program without a for loop.</p><p>Recursion is — generally speaking — less intuitive and human-understandable than iteration.</p><p>Perhaps that’s why declarative programming is nowadays an uncommon paradigm that only a few of us know.</p><p>It is not difficult, but unintuitive, and we are not <em>programmed </em>to program recursively. In case you don’t know those programming paradigms:</p><ul><li><a href="https://www.google.com/url?sa=t&amp;rct=j&amp;q=&amp;esrc=s&amp;source=web&amp;cd=&amp;cad=rja&amp;uact=8&amp;ved=2ahUKEwjD7ePxkcv3AhXbh_0HHUnUBvkQFnoECAUQAw&amp;url=https%3A%2F%2Fwww.techtarget.com%2Fwhatis%2Fdefinition%2Fimperative-programming&amp;usg=AOvVaw1bx6SRy4VnfZ46rfSwa-PG">Imperative Programming</a></li><li><a href="https://www.techtarget.com/searchitoperations/definition/declarative-programming">Declarative Programming</a></li></ul><p>Declarative programming is known as a superset of functional programming and logical programming, but it is sometimes interchangeably referred as functional programming due to its high popularity.</p><p>Logical programming is built on relations and predicates, and the variable assignment is achieved under unifications and resolutions ( = a depth-first search algorithm for finding any solution which suits well to the condition).</p><p>We will see more on functional programming in the next sections.</p><h4>Key Features of Functional Programming</h4><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*tAbUwe7JqqeoPJhnjrmJXQ.png" /><figcaption>Source: <a href="https://www.xenonstack.com/insights/functional-programming">https://www.xenonstack.com/insights/functional-programming</a></figcaption></figure><p>In general, Functional Programming has the following key features:</p><p><em>First-class functions:</em> Everything is a function.</p><ul><li>Variables and constants are also functions which don’t take any arguments.</li><li>So a function results always to a function when called.</li><li>With this in mind, a function can be also partial — intermediate states of a function are also functions.</li><li>For example: “=” with 2 arguments, checks whether both numbers are equal.</li><li>“=5” with one argument, checks whether a number is equal to 5.</li><li>“5=5” is a variable ( = a function with no argument), which results to true.</li></ul><p><em>No modification: </em>Functions are immutable.</p><ul><li>Variables and data structures are constant, because they are functions.</li><li>If a variable X is assigned 5, it cannot be changed to 6.</li><li>Neither the list Y = [3, 7, 5] nor its elements can be modified, since lists are also recursive data structures.</li></ul><p><em>No loop: </em>No iteration, just recursion.</p><ul><li>Since there are also no variable modifications, it is not allowed to define a counter.</li><li>Instead of for-loops and while-loops, iterating over a list or other recursive data structures is the way to do.</li></ul><p><em>Lazy Evaluation: </em>No CPU overload.</p><ul><li>Functional programming takes advantage of the power of recursion.</li><li>Even if the recursion doesn’t end, the number of calculated results depends on how many results are taken.</li><li>Let’s assume we calculate the first n numbers of a set with an open interval such as ones, zeros or natural numbers {0, 1, …}.</li><li>If we ‘take’ the first n = 30.000 numbers, more results will be cached compared to n = 30.</li></ul><p><em>Higher-order functions: </em>We will see more details in the next sections.</p><h4>Key Mathematical Concepts Related to Relations</h4><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*A-uQUceI1K7hr6oFROj6bQ.jpeg" /><figcaption>Source: <a href="https://de.cleanpng.com/png-u9elqf/">https://de.cleanpng.com/png-u9elqf/</a></figcaption></figure><p>Did you know that functional programming shares too many similarities with math language, logic and SQL?</p><p>The reason behind the similarity is that all of them are built on relations, but we will get later into it.</p><p>This article is strongly linked to my other article: <a href="https://yamaceay.medium.com/logic-is-built-on-relations-371ea2a547aa">Logic is Built On Relations</a>.</p><p>I wrote about the fact that relational databases, programs in object oriented style and logical structures have something in common, along with a gentle introduction to Boolean Logic and First-Order Logic.</p><p>If you are not a math person, check this out: <a href="https://yamaceay.medium.com/sets-tuples-ef4a975c80c7">Sets &amp; Tuples</a>, which makes a brief introduction to overview of features, similarities and operations on sets and tuples.</p><h4>Relations &amp; Functions</h4><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*JdXtqMAB5MsZ1m9COiQ2cQ.jpeg" /><figcaption>Source: <a href="https://www.expii.com/t/when-is-a-relation-a-function-4325">https://www.expii.com/t/when-is-a-relation-a-function-4325</a></figcaption></figure><p><em>Universal Set: </em>The set of all values.</p><ul><li>Since we make a closed world assumption ( = all we know is all it exists in the universe), universal set contains all ‘existing’ elements and nothing more.</li><li>It is generally used to show the all possible combinations, for example when we define a relation.</li><li>Keyword: dictionary, capacity of information.</li></ul><p><em>Relation</em>: A subset of universal set.</p><ul><li>Assuming A is the universal set, a n-ary relation R is a subset of A × … × A = A^n, so it is basically a set of tuples.</li><li>Notation: R : (A_1, …, A_n)</li><li>Each tuple in set holds a unique information and there are a set of such information.</li><li>It holds the information that we make use of in our closed world assumption.</li><li>The information is binary, since we can only check, whether a relation contains an element.</li><li>Keyword: actual information, attribute.</li></ul><p><em>Function: </em>A special type of relation.</p><ul><li>Functions are relations which basically map each domain value to a co-domain value (domain set is the set of all inputs, co-domain is the set of all outputs).</li><li>Currying f: (A, B) to f: A → B makes a function out of relation. Uncurrying f: A → B to f: (A, B) makes a relation out of function.</li><li>In general, if a relation f : (A_1, …, A_n, B_1, …, B_m) meets the conditions of being a function, it can be curried as f : (A_1, …, A_n) → (B_1, …, B_m)</li><li>(A_1, …, A_n) is the domain and (B_1, …, B_m) the codomain.</li><li>Notice that domain and co-domain can be a cross product of multiple sets.</li><li>If (a_1, …, a_n, b_1, …, b_m) ∈ f, then f((a_1, …, a_n)) = (b_1, …, b_m).</li></ul><h4>Currying and Partial Functions</h4><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*0dlhtNId3TpI_cvKbudOvw.png" /><figcaption>Source: <a href="https://en.wikipedia.org/wiki/Currying">https://en.wikipedia.org/wiki/Currying</a></figcaption></figure><p>Mostly in functional programming and math universe, the functions are curried, which is why partial functions are allowed.</p><p>Let’s assume that f is an uncurried function f : (A_1, …, A_n).</p><p>It doesn’t have a intermediate state. It returns an output as a constant function, if and only if every value (a_1, …, a_n) is successfully passed as an argument.</p><p>Let’s assume i ∈ {0, …, n-1} is a number.</p><p>f : (A_1, …, A_i) → A_{i+1} → … → A_n is a function which returns a function if every value (a_1, …, a_i) is successfully passed.</p><p>If i = 0, every A_i is joined by → and the tuple on the left side is empty.</p><p>Now the function looks like this: f : () → A_{1} → … → A_{n} or simply f : A_1 → … → A_n.</p><p>It is a function which always returns:</p><ul><li>a partial function with the missing arguments</li><li>or an output value if all arguments are passed</li></ul><p>In functional programming languages such as Haskell, the function looks like f : A_1 → … → A_n, because of the first rule: everything is a function.</p><h4>Functional Programming: Functionals</h4><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*1GxrFR4FIs8v6ZxDNGXiXA.png" /><figcaption>Source: <a href="https://realpython.com/python-functional-programming/">https://realpython.com/python-functional-programming/</a></figcaption></figure><p>Now that we have a grasp of basic concepts, it’s time to refresh what we know about functional programming:</p><p><em>Map</em>: A function f : A → B which mappes each value a_i to f(a_i) = b_i.</p><ul><li>If we would allow B to be a multi-set or bag where duplicates are allowed, B would still have the equal number of elements.</li><li>However mathematically, we will simply assume B is a set too, so if there are at least two values a_i ≠ a_j with f(a_i) = f(a_j), the number of elements on both sides will be different: |A| &gt; |B|.</li><li>In OCL, it is referred as →collect(x : Real | f(x)) where you need to define the mapping function f.</li><li>It is also very similar to π (projection operator in Relational Algebra) and SELECT (projection keyword in SQL).</li></ul><p><em>Filter</em>: A relation R ⊆ (A_1, …, A_m) which contains a subset of all possible values.</p><ul><li>It is possible to identify the values (a_1, …, a_m) contained in R using (a_1, …, a_m) ∈ R.</li><li>Alternatively, we can define a characteristics function p: (A_1, …, A_m) → {0, 1} with p((a_1, …, a_m)) = 1 if (a_1, …, a_m) ∈ R and else 0.</li><li>With this function in mind, we can define a filter function f: (A_1, …, A_m) → R where f((a_1, …, a_m)) = (a_1, …, a_m) if p((a_1, …, a_m)) = 1 and else ⊥ (undefined).</li><li>In OCL, it is referred as →select(x : Real | p(x)) where you need to define the predicate function p.</li><li>It is also very similar to σ (selection operator in Relational Algebra) and WHERE (selection keyword in SQL)</li></ul><p><em>Reduce: </em>A function f : (A_1, …, A_m) → B which reduces the input to a summary value.</p><ul><li>It can be a sum or multiply function, cosine similarity function, mean — mode — median function, where each b = f((a_1, …, a_m)) is a scalar value.</li><li>It is the most representative function among those 3 functions, because reducing function can be a structure-holding function.</li><li>For example: it can be a pass function or a mapping function where b is defined as (b_1, …, b_m).</li><li>In OCL, it is referred as →iterate(x : Real, acc : Real = &lt;acc&gt;| f(x, acc)) where you need to define the function f and accumulator value acc.</li><li>Relational Algebra: Such operations can be done using Ɣ, groupby-aggregate operator. It takes two kinds of input: columns to be grouped by and columns to be summarized.</li><li>SQL: Likewise GROUP BY, groupby-aggregate-keyword.</li></ul><p><strong>[BONUS]</strong> <em>Zip:</em> A function f which compresses the sets A, B with n elements to a set of pairs.</p><ul><li>Definition: f({a_i | 1 ≤ i ≤ n}, {b_i | 1 ≤ i ≤ n}) = {(a_i, b_i) | 1 ≤ i ≤ n}, n = |A| = |B|.</li><li>It can be rewritten using reduce function which uses a structure-holding function internally.</li><li>Unzip function is the inverse function of zip, which maps both elements in the pair a_i, b_i to their original set.</li></ul><h4>Next Chapter</h4><p><em>It is the first chapter of Science Loves Declarative Style, and you can navigate to the next chapter clicking </em><a href="https://yamaceay.medium.com/science-loves-declarative-style-2-806c5f28e96d"><em>here</em></a><em>.</em></p>
