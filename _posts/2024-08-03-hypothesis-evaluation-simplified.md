<h4>Model evaluation and risk optimization in case of corona detection and treatment</h4><p>In this article, I want to illustrate hypothesis evaluation using a simple classification example: Corona detection (instead of the more typical choice of “cancer detection”.)</p><p>Assume that there is a one-dimensional measurement called <em>X ≥ 0</em> (e.g., the ratio of viruses). The task is to find the most plausible decision boundary <em>k</em>, also the minimum ratio of allowed markers indicating corona, below which all patients should be corona-free. This decision can be characterized by a binary variable <em>Y</em> with “corona” (1) or “no corona” (0).</p><figure><img alt="2-dimensional visualization of a classification problem with four different labels." src="https://cdn-images-1.medium.com/max/275/1*ZFHVb0N3S--FcFK-TGXsYA.jpeg" /><figcaption>Classification. <a href="https://ai.thestempedia.com/extension/number-classifier-and-regression-ml/">Source.</a></figcaption></figure><p>Each classifier program can be characterized by a function <em>f: X → Y</em>, which tells the patient whether they have corona or not. Note that this article doesn’t cover how such a classifier can be developed; it is primarily within the scope of machine learning and inferential statistics. The main question is: Given a list of classifiers, which classifier is the most favorable?</p><p>Let’s start with a synthetic case, where even a toddler could draw a line that separates both groups perfectly. In this scenario, our classifier would be 100% accurate.</p><figure><img alt="Visualization of a case where all observations below x = 8 have false labels, and all other observations have true labels." src="https://cdn-images-1.medium.com/max/445/1*X26StMhGA13ONW6LL72OMQ.png" /><figcaption>In this ideal setup, we can draw the optimal boundary at X = 8</figcaption></figure><p>But what if both groups are not completely separable? If we decrease the separability of both groups, it gets increasingly difficult to separate them using a linear decision boundary, as seen below:</p><figure><img alt="Three visualizations, each being less separable than the previous one. The zero- and one-observations intersect more if the data is less separable." src="https://cdn-images-1.medium.com/max/476/1*3D-_wLvs-qYrCXgEUDEy6A.png" /><figcaption>With the decrease in separability, the classification error increases as well</figcaption></figure><p>In such cases, we have to optimize the error and find a balance between telling people with corona that they don’t have it and telling people without corona that they have it. Let’s consider the use case with <em>separability = 2</em>. We’re given a simple logistic regression model, which learns a binary decision boundary by being trained on a different dataset:</p><figure><img alt="Visualization of a logistic curve, which represents the certainty of the data point being labeled as true, and can be used for classification." src="https://cdn-images-1.medium.com/max/567/1*XPxFwZdl7y80DRTq4HmU_A.png" /><figcaption>Logistic regression learns P(Y = 1 | X), also the conditional probability of Y = 1 given X</figcaption></figure><p>Using that probability prediction, we can set different threshold values for corona detection and collect the number of correct and incorrect predictions for both outcomes. There are four different cases we need to consider:</p><ul><li><strong>True Positive [ TP ]:</strong> The model successfully detects that a person has corona.</li><li><strong>False Positive [ FP ]</strong>: The model incorrectly alarms a healthy person.</li><li><strong>False Negative [ FN ]</strong>: The model fails to detect corona in a person.</li><li><strong>True Negative [ TN ]</strong>: The model successfully detects that a person is corona-free.</li></ul><p>Confusion matrix is a great way to visualize such statistics:</p><figure><img alt="Confusion matrix with the first column (representing the possible results for negative prediction) containing True Negative (TN) and False Negative (FN), and with the second column (representing the possible results for positive prediction) containing False Positive (FP) and True Positive (TP). The first and second row represents the case where the real label is false and true respectively." src="https://cdn-images-1.medium.com/max/289/1*pPJx6thslGg9HTIKNRV9AQ.png" /><figcaption>An example of confusion matrix</figcaption></figure><p>In the image below, you can see the confusion matrices for different threshold values:</p><figure><img alt="Confusion matrices with different threshold values, namely 0.1, 0.3, 0.5, 0.7 and 0.9." src="https://cdn-images-1.medium.com/max/1024/1*VNmXZsdlqs5QOnZ4JeGYvQ.png" /><figcaption>Confusion matrices for different thresholds</figcaption></figure><p>Notice that, from left to right, the number of <strong>TP</strong>s decreases while the number of correct <strong>TN</strong>s increases. The obvious reason: Increasing the threshold has the same effect as reducing the number of positive predictions, and vice versa.</p><p>At first glance, we would pick the one that yields the highest number of accurate predictions. Enter the <em>accuracy score</em>, which is calculated as <strong>TP + TN</strong> divided by the number of patients. Below, you can see the corresponding accuracy scores:</p><figure><img alt="Accuracy ratios for given thresholds, plotted in a line curve, which are roughly located at 70-80% regardless of the choice." src="https://cdn-images-1.medium.com/max/567/1*DTiUzf3WI8gfkpFlqJ2Wgg.png" /><figcaption>Accuracy ratios for different thresholds</figcaption></figure><p>Accuracy ratios for different thresholds, which guide us to the one with <em>threshold = 0.3</em> as the most optimal choice. Looks nice!</p><p>In reality, this doesn’t tell us the whole story. What if <em>1 + 1</em> is not equal to <em>2</em>, or if failing to diagnose corona is more critical than a false corona alarm? So, we need better measurements:</p><ul><li><strong>Precision [ TP / (TP + FN) ]: </strong>Given that a person is tested positive, how likely is the person to have corona?</li><li><strong>Recall [ TP / (TP + FP) ]:</strong> Given that a person has corona, how likely will the person be tested positive?</li></ul><p>Now, let’s try out more threshold values and plot both precision and recall against the new thresholds:</p><figure><img alt="Similar plot as before, but this time precision and recall curves are plotted against threshold (with step size of 0.02). Precision starts from 1.0 and decays until 0.3, while recall starts from 0.6 and rises until 1.0. Visually, both curves intersect if the threshold is 0.5." src="https://cdn-images-1.medium.com/max/567/1*mMr2b_Bmvwuu74oMHzhvxA.png" /><figcaption>Precision and recall against threshold</figcaption></figure><p>As you may notice, the precision hardly decreases and recall hardly increases, so they must intersect in the middle (e.g., <em>X ≈ 0.5</em> in this example). The contrast between precision (<strong>P</strong>) and recall (<strong>R</strong>) leads to the following question: Is there an “average” metric that brings the best of both metrics (also kind of maximizes their lower bound)?</p><ul><li><strong>Arithmetic mean [ (P + R) / 2 ]:</strong> Sum of both metrics divided by <em>2</em>. It would be useful if both metrics had the same unit (scale), where <em>1 + 1 = 2</em> would make sense.</li><li><strong>Geometric mean [ √(P × R) ]: </strong>Square root of the product of both metrics. It would be most useful if both metrics had different scales. In the case of ratios ranging from <em>0</em> to <em>1</em>, the smaller value makes the overall result smaller (or dominates).</li><li><strong>Harmonic mean [ (2 × P × R) / (P + R) ]: </strong>Reciprocal of the arithmetic mean of reciprocals (<strong>1 / P</strong> and <strong>1 / R</strong>). Simplified as the product of both metrics divided by the arithmetic mean. Smaller values in the harmonic mean are even more dominant than those in the geometric mean, so extremely low values are penalized more strongly.</li></ul><p>In fact, the last option, the harmonic mean of precision and recall, is the well-known <strong>F1-Score</strong>. You are welcome to compare all metrics below:</p><figure><img alt="The same plot as before, but this time, arithmetic mean, geometric mean and harmonic mean scores are plotted as well. They all intersect at the same point. Harmonic mean is always smaller than geometric mean, which is smaller than arithmetic mean." src="https://cdn-images-1.medium.com/max/567/1*_G-cWWd4LsbpDecBDrFrZQ.png" /><figcaption>Precision, recall, arithmetic mean, geometric mean and harmonic mean plotted against threshold</figcaption></figure><p>The limitation is that such “symmetrical” average metrics cannot distinguish between precision and recall. Remember that some predictions are bad, but others are worse. For example, a false negative could be more risky than a false positive. What if recall is three times more important than precision?</p><p>Now, let’s define <em>β</em> as the risk factor, also the hyperparameter, which controls the influence of recall in our new mean metrics. So, let’s adjust the definitions as follows:</p><figure><img alt="The definitions of (weighted) arithmetic, geometric and harmonic mean. Beta is the hyperparameter, which is used to control the asymmetry between precision and recall." src="https://cdn-images-1.medium.com/max/690/1*x_8ddTkLExfY0yK6YL8Wiw.png" /><figcaption>(Weighted) arithmetic mean, geometric mean and harmonic mean</figcaption></figure><p>Now, here is the most interesting part: With the increasing <em>β</em>, the importance of recall in the harmonic mean increases, while in the arithmetic and geometric mean, it’s exactly the opposite.</p><figure><img alt="With the increasing threshold, arithmetic and geometric mean diverge from recall and converge towards precision." src="https://cdn-images-1.medium.com/max/1024/1*OO0x7Y1u54w-oDEYCiMLaA.png" /><figcaption>From left to right: Arithmetic and geometric mean converge towards precision</figcaption></figure><figure><img alt="With the increasing threshold, harmonic mean diverge from precision and converge towards recall." src="https://cdn-images-1.medium.com/max/1024/1*AAzzryWakytjMJsqqztmoQ.png" /><figcaption>From left to right: Harmonic mean converges towards recall</figcaption></figure><p>So, here is an intermediate summary:</p><ul><li>More than often, the number of correct predictions is not entirely informative, so we need precision and recall as evaluation metrics.</li><li>Precision and recall have a mostly inverse relationship, so their “average” metric might help estimate the goodness of the models.</li><li>Symmetrical average scores such as F1-score can be optimized for asymmetric use cases by weighting, depending on how risky the false positive or false negative is.</li></ul><p>In the previous part, we learned how to find the most optimal model by applying evaluation metrics in the case of corona detection. In this part, let’s follow up with a similar task: Find the corona treatment with the lowest overall risk.</p><p>Given any prediction, we’ll assess the risk of applying a treatment. The variables are defined as follows:</p><ul><li><strong>Treatment [ T ]</strong>: The action taken to cure the disease. For simplicity, let’s assume there are three treatment methods: <em>“A”, “B”, “C”</em> and the fourth option is: “-” (no treatment).</li><li><strong>Sickness [ Y ]</strong>: Whether the patient is sick or not.</li><li><strong>Prediction [ M ]</strong>: The result of the corona test.</li></ul><p>In our case, the risk function <em>r(T | Y)</em> is given as follows:</p><figure><img alt="Risks of treatments given the sickness states of patient (with false as corona-free and true as having corona), represented in a matrix with treatments as rows and sickness states as columns. If the patient is positive and no treatment is applied, then the risk is at its highest. If the patient is negative and no treatment is applied, then the risk is zero." src="https://cdn-images-1.medium.com/max/318/1*FWQ05_pyUgUldvtBdJzoCQ.png" /><figcaption>Risk matrix</figcaption></figure><p>For this task, I set the threshold of the classifier to <em>0.4</em>, which provably yields a very high F1-score (as shown previously). Using that, we can compute the confusion matrix. Next, let’s obtain the probability distribution <em>P(Y | M)</em> from the confusion matrix by dividing each entry by the sum of the corresponding column, respectively, which provides us with the certainty of predictions:</p><figure><img alt="Left plot is the confusion matrix quantifying the certainty of predictions. Right plot is the column-wise normalized confusion matrix, which represents a conditional probability distribution at each of both columns." src="https://cdn-images-1.medium.com/max/833/1*9Utc1sKbcLKMUCQY5w_yuw.png" /><figcaption>Obtaining certainty of predictions by confusion matrix</figcaption></figure><p>Calculating the expected risk R of a treatment <em>T</em> given a prediction <em>M</em> is notoriously simple:</p><ul><li>The probability that a person has corona given a prediction <em>M</em> is multiplied by the risk of applying a treatment <em>T</em> if a person has corona. <em>R(T, Y = 1, M) = r(T | Y = 1) P(Y = 1 | M)</em></li><li>Likewise, the probability that a person is corona-free given a prediction <em>M</em> is multiplied by the risk of applying a treatment if a person is corona-free. <em>R(T, Y = 0, M) = r(T | Y = 0) P(Y = 0 | M)</em></li><li>Their sum <em>R(T, M) = R(T, Y = 0, M) + R(T, Y = 1, M)</em> is the expected risk of a treatment given a prediction.</li></ul><p>In general, the expected risk function might look like this:</p><figure><img alt="Formula saying that the expected risk of a treatment given a prediction is the sum (over both cases) of the treatment risk given the sickness multiplied by the certainty of sickness given the prediction." src="https://cdn-images-1.medium.com/max/606/1*iZLfaSLujliMgUwhwUZ_4w.png" /><figcaption>Expected risk of a treatment given a prediction</figcaption></figure><p>Now, let’s perform the risk assessment and find the best treatment for each case:</p><figure><img alt="The calculated expected risks with each row representing the treatments and each column representing the predictions." src="https://cdn-images-1.medium.com/max/318/1*EzTyIS3-CWnIViixbrVO1g.png" /><figcaption>Risk assessment</figcaption></figure><p>Obviously, a person with a negative corona test should not be treated, since the chances are very low that the prediction is a false negative, which implies a very low risk of not getting a treatment despite being sick. Secondly, applying the first treatment “<em>A”</em> yields the lowest amount of risk on average if the corona test is positive.</p><p>In real-world scenarios, inputs are often sparse and exist across thousands of dimensions, making accurate predictions challenging. Advanced algorithms like gradient descent are essential to minimize loss and improve decision-making. This article emphasized the significance of balancing precision and recall in model evaluation and treatment risk assessment. However, there is much more to explore. Topics such as hypothesis testing, t-tests, and chi-square tests, which we didn’t cover here, could be the focus of my future articles.
