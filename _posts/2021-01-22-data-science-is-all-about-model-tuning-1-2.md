<p>That’s just the tip of the iceberg. Here’s a full guide of iceberg.</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*XWc_9bAmqDtgC_YqnyPlrw@2x.jpeg" /><figcaption>By: <strong>Joshua Sortino, </strong>Unsplash</figcaption></figure><p>Nowadays, it is a quite popular belief that a perfect Data Scientist is a Kaggle grandmaster with golden medals at every competition he/she attends. I do not disagree that being a Kaggle grandmaster is not an easy thing to do. In fact, there are nearly 150k Kagglers out there in the world and only a 0.1% portion of these are grandmasters with a lot of golden and silver medals in many different areas at the same time. I would say this is a huge success but<strong> it actually does not define how a perfect Data Scientist should be</strong>.</p><p>The power of data scientist is actually underestimated. Data Scientists are not just Kagglers, who only write code in an isolated Jupyter environment. Data Scientists are not just ML engineers, who excel in tuning hyperparameters of a NLP model. Data Scientists are <strong>a more diverse group</strong>, they are economists, CEOs, storytellers, students…</p><p>In this article, I will explain step by step how to create <strong>your own</strong> Data Science project.</p><p>Data Science is not a linear process. If you are at Step 4, then you may be return to Step 2 for some reason. It is seen as a<strong> circular</strong> process, which repeats itself and learns from its feedbacks. These are 6 Steps I usually deal with when making a project.</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*V1017jHWqdvj86iiOUWmhg@2x.jpeg" /><figcaption>By: <strong>Matt Walsh</strong>, Unsplash</figcaption></figure><h4>Step 1: Identify Question</h4><p>To start a new data science project, you need to have a great <strong>thought-provoking statement</strong> at hand. If your statement is not clear, then it can lead to misunderstandings at later stages. It can be an argument, a question. And most importantly, you need to be able to find <strong>a suitable metric</strong> applicable to your question. Let’s look at the following examples:</p><p>How is the weather going to be here tomorrow?</p><ul><li><strong>Better Question: </strong>Will it rain in the next few days in Berlin?</li><li><strong>Metric:</strong> Humidity, the quote of rainy days to sunny days in the previous month in Berlin etc.</li></ul><p>How can I get rid of being tired all the time?</p><ul><li><strong>Better Question:</strong> Does consuming too much caffeine at a daily basis have a negative effect on sleeping patterns in the long term?</li><li><strong>Metric:</strong> Daily changes of energy levels of test (no-caffeine) and control (caffeine) groups over the course of 2 months etc.</li></ul><p>How to be more up-to-date in web development?</p><ul><li><strong>Better Question:</strong> What are the top 5 most popular frameworks these days according to programming subreddits?</li><li><strong>Metric:</strong> The number of upvotes, The number of comments etc.</li></ul><p>I think you get the gist. Let’s proceed with the second crucial step.</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*iLO1kEWWI2KcSh4xD_ThoA@2x.jpeg" /><figcaption>By: <strong>Edgar Chaparro,</strong> Unsplash</figcaption></figure><h4>Step 2: Find Data</h4><p>No data, no model. You need a <strong>reliable</strong> data source to answer the question. Usually, open-source datasets are the most desirable choice and you can find every kind of datasets online (e.g. Kaggle datasets, GitHub repositories).</p><p>However, if you need <strong>very case-specific and unique</strong> data for your purpose, it can be very challenging to find the right data. In this case, you might need to create a dataset from zero. You can get access to a Web API (websites that gives you the access to data in a specific file format, for example JSON or CSV files) or even do web-scraping, which makes you even more powerful.</p><p>A great portion of entire data is <strong>unstructured</strong>: videos, audios, images, texts etc. Using pre-trained models for <strong>feature extraction</strong> may unlock the hidden potential of such data, e.g. a NLP model for Sentiment Analysis or a Computer Vision model for Object Detection &amp; Image Classification. You can do basically anything with this loads of data, anything!</p><p>If your data is too big in size, you might need to know how Cloud Computing and Distributed Computing works. In general, Cloud Computing provides access to software &amp; hardware tools and Distributed Computing speeds up computation by distributing the task to many computers simultaneously. If you are interested, check out the following tools:</p><ul><li><strong>For Cloud Computing:</strong> AWS Amazon, Google Cloud, IBM Cloud…</li><li><strong>For Distributed Computing:</strong> Spark, Dask, Vaex, Hadoop…</li></ul><figure><img alt="" src="https://cdn-images-1.medium.com/max/1400/1*M7Gcmlo3tuSTJ8uFrtt-SA@2x.jpeg" /><figcaption>By: <strong>Alev Takil, </strong>Unsplash</figcaption></figure><h4>Step 3: Fix Data</h4><p>Not every data is equal and there is no such thing as perfect data. Some may have inconsistencies, some may have missing values, especially if you have scraped unstructured data. Things to do before getting to the analysis part:</p><p>The essential operations:</p><ul><li>Check if the names of columns are <strong>consistent</strong></li><li>Find and delete <strong>duplicate</strong> records</li><li>Find <strong>missing</strong> values and either drop the column with missing values or fill the missing values by zero, mean, mode, median etc.</li><li>Find out<strong> wrong</strong> values and replace with the right values</li><li>Detect <strong>outliers</strong> and delete/replace them.</li></ul><p>If necessary:</p><ul><li><strong>Sort</strong> values by an id column or create one</li><li>Group values of a numeric feature into smaller number of <strong>bins</strong>.</li><li><strong>Convert categorical values</strong> into numerical values by One-Hot Encoding, Label Encoding etc.</li></ul><p>Now we are in the halfway of creating a project. We will go even deeper in the next article.
